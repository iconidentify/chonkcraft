Droid Serif
===========

Regular and Bold, used for every piece of text the game draws.

Digitized data copyright (c) 2007, Google Corporation.
Licensed under the Apache License, Version 2.0.

    https://www.apache.org/licenses/LICENSE-2.0

Shipped inside the jar rather than looked up by name on the machine, so the
game reads the same on every one of them. A font resolved by family name is a
font that is one uninstall away from being something else, and the sidebar is
laid out to the width of the lettering in it.

The licence permits redistribution; that is why this face and not one of the
handsomer ones the operating system happens to provide. Optima and Palatino
both suit a stone panel better and neither may be shipped.
